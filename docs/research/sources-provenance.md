# Provenance of the documents used

Every document read for the program or the article, with where it came from.

- Licensed documents (standards, paywalled articles) and their text extracts are used locally only and are
  **not** in the repository (project rule, `status.md` §6).
- Free documents are not stored either; their links are below and in `references.bib`.
- The working copies of the cloud environment are temporary. A new session obtains them again from these
  sources.
