# Research notes

This folder is kept as if every entry will be read by a journal reviewer.

| File | Purpose |
|---|---|
| `research-log.md` | dated laboratory notebook: decisions (D), findings (F), open questions (Q) |
| `literature-review.md` | standards, methodological papers, competing software, gap analysis, search protocol |
| `validation-matrix.md` | every reference case, its source, published vs. computed values, tolerances |
| `publication-plan.md` | target journals, contribution claims, manuscript outline, checklist |
| `references.bib` | BibTeX of sources actually read or confirmed |
| `documents-needed.md` | paywalled / missing documents the author will obtain (TR) |
| `iso17025-mapping.md` | ISO/IEC 17025:2017 clauses on uncertainty, reporting and software, mapped to the program and its gaps |

Rules: cite primary sources by clause; mark anything not yet read as
*to verify*; never edit past log entries — add a new dated entry instead;
every number in the article must be reproducible from the repository.
