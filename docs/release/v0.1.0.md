First public release of **KAPSAM**, open-source software for the evaluation of measurement uncertainty (TÜBİTAK UME).
This is the version described in the article submitted to *Measurement*; every number of the article can be
reproduced from it (`cargo test`, scripts in `tools/research/`).

**Evaluation types:** measurement models (law of propagation of first and second order, Welch–Satterthwaite with
ensembles, Kragten, adaptive Monte Carlo of JCGM 101), several outputs (JCGM 102), conformity assessment (JCGM 106,
guard bands, global risks), top-down evaluation (Nordtest, MUPR, ISO 21748), proficiency testing (ISO 13528),
calibration with uncertainty in both variables (ISO 6143), precision experiments (ISO 5725-2/-3), control charts
(Nordtest TR 569), uncertainty from sampling (Eurachem UfS), weighing instruments (EURAMET cg-18) and consensus values
with degrees of equivalence (NIST Consensus Builder). Reports in English and Turkish as Markdown, HTML, PDF, JSON
and spreadsheet verification workbooks (.xlsx).

**Validation:** a library of 286 self-checking projects from the worked examples of 38 documents (1865 reference
values, all reproduced within their tolerances), compared with Suncal 1.7.1 (171 projects) and recalculated with
spreadsheet formulas in LibreOffice Calc (189 projects). `kapsam check library --report validation.pdf` writes a
software validation report for ISO/IEC 17025 7.11.2.

**Packages:** Windows (x64, zip; not code-signed), Linux (x64, tar.gz), Android (apk), macOS (zip) and iOS
(unsigned build). The command-line tool is built from source with `cargo build --release -p uncertainty-cli`.
